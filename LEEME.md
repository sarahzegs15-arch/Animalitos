# Patitas y Mimitos

App interactiva para bebés (funciona sin internet una vez instalada).

## Publicar con GitHub Pages
1. Crea un repositorio nuevo en GitHub (público).
2. Sube estos archivos a la raíz del repositorio: index.html, sw.js, manifest.json, icon.png.
3. Settings > Pages > Branch: main, carpeta / (root) > Save.
4. Espera 1-2 minutos y abre la dirección https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/ en Safari del iPad.
5. Compartir > Añadir a pantalla de inicio. Ábrela una vez con internet.
